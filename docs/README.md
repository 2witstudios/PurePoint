| Folder | What's in it |

| [`reference/`](reference/) | Schemas and maps: config, manifest, IPC API, directory layout, CLI commands. |
| [`design/`](design/) | UI/UX principles, rules and rubric, plus HTML [mockups](design/mockups/). |
| [`process/`](process/) | How work gets done: TDD, code review, spec advancement, task planning. |
| [`research/`](research/) | Background research cited by specs. |
| [`images/`](images/) | Screenshots used by the README and guides. |

[`spec-system.md`](spec-system.md) explains how specs are organized and how they mature. [`vision.md`](vision.md) explains why PurePoint exists.
