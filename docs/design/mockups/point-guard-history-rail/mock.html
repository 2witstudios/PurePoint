Point Guard history rail: current vs proposed

The rail is a separate black block that starts below the tab strip, with its own margin and rounded card. It never meets the top of the pane, so it reads as a floating panel rather than part of the chrome. The proposal makes the rail the same band as the tab strip. Both use one color, the header row sits at the tab strip's height, and the hairline runs the full pane height.

1 · One band, not a floating cardThe rail starts at the top of the pane and shares the tab strip's 36px row, so the strip and the rail read as one piece of chrome. Both use the tab-bar color (#141417). The rail's header is the first segment of the strip, which keeps the toggle on the same baseline as the tab.
#141417 strip + rail#1C1C1F chat
2 · Hairlines do the separatingThe rail has no margin, no inner radius and no drop shadow. A single 1px divider at 6% white runs from the top of the pane to the bottom, and the footer's rule matches the strip's bottom edge. The rail's footer sits flush with the pane's bottom edge, not inside a rounded card.
3 · Collapsed keeps the same seamWhen hidden, the rail shrinks to a 36px segment with only the toggle. It stays in the strip row, so the toggle never jumps. The chat still starts directly under the active tab, so the tab connects to the content the way a terminal tab does.
