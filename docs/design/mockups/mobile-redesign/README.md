# iPhone redesign — the sidebar is the app

Source snapshot of the design canvas (https://claude.ai/artifact/6wHJpUvHRXYmD9ydFAFoHU) the iPhone app implements. Each `*.dc.html` is one 390×844 artboard; `canvas.json` is the layout and board titles. The artboards load the canvas runtime (`support.js`) and an uploaded logo, so open them from the canvas rather than directly.

Rows: home sidebar, agent workspace and Point Guard (new conversation with draggable plays, conversation); sheets (Connections, pairing scanner, one-tap New dialog, unconfirmed launch, name alerts); Point Guard history, input dialog, saved prompts and stop confirmations; composer, chat access, home and agent states, and the agent row menu.
