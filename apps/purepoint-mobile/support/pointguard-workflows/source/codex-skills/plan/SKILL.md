# Plan

Use the shared task skill and repository agent pipeline as the source of truth.
Read AGENTS.md, product intent and relevant architecture before drafting.
Create or update one durable plan with a concrete manifest, build inputs,
acceptance dependencies, provisional source SHAs, actual writer conflicts and
proof obligations. Obtain independent plan feedback and fix material findings.

A planning-only request ends with the reviewed plan for owner discussion; it does
not authorize implementation. An instruction to implement an outcome already
authorizes routine planning, tasking, delegation and review fixes. Do not insert
another owner-approval stage into that delivery. Escalate changed product intent
or protected human-only actions while continuing unaffected work.

Resume existing records rather than duplicate them. Record supplied owner
steering accurately. Use task workflow for tasking/replanning, then orchestration
for delivery. Board artifacts document authority; they do not create it.
